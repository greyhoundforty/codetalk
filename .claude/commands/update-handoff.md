# Update Handoff Document

Update the existing `.system-prompt-extraction/NEXT-STEPS.md` file with current session progress.

## Task

Read the current NEXT-STEPS.md file and update it with:

### 1. Mark Completed Tasks
- Check off any tasks from "Actionable Next Steps" that were completed
- Move completed items to "What Has Been Completed" section

### 2. Add New Progress
- Document what was accomplished in this session
- Include any new files created or modified
- Note any important decisions or discoveries

### 3. Update Current State
- Refresh the "Current State" section
- Update any blockers that were resolved
- Add new blockers if any emerged

### 4. Revise Next Steps
- Add new tasks based on current progress
- Reprioritize existing tasks
- Remove tasks that are no longer relevant

### 5. Update Timestamp
- Add a session log entry:
```markdown
## Session Log
- [YYYY-MM-DD HH:MM] - [Brief summary of what was done]
```

## Instructions

1. Read the existing NEXT-STEPS.md file first
2. Make updates preserving all critical context
3. Keep the document concise - remove outdated information
4. Maintain the same structure and formatting
5. Confirm what was updated

This keeps the handoff document current without starting from scratch.
